API Referans

Tüm endpointler JSON döner: { ok: true|false }

Endpointler
GET    /api/health
GET    /api/sessions
POST   /api/sessions/:slot/start
GET    /api/sessions/:slot/status
DELETE /api/sessions/:slot

POST   /api/send
{
  "slot": 1,
  "number": "905xxxxxxxxx",
  "text": "merhaba"
}

POST   /api/send/bulk
{
  "slot": 1,
  "numbers": ["905xx","905xx"],
  "text": "merhaba"
}

POST   /api/send/media
{
  "slot": 1,
  "number": "905xx",
  "url": "https://…/photo.jpg",
  "caption": "selam"
}

# opsiyonel auth header:
X-API-Key: (API_KEY)
